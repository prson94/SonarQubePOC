Auto Focus Directive

Angular directive that can be applied to any HTML element.

AutoFocuses element when container is visible for the first time. Works similiar like HTML autofocus attr., but autofocus attribute works only on pageload which causes elements that are hidden with *ngIf or in modal popup not being autofocused when element is visible.
