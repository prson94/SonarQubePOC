Modal Drawer component

Govern modal UI component.

The modal component opens as a dialog on the right side of window

The modal can always be dismissed by pressing the ESC button.

Modal content is defined using 3 content templates: header,content,action.

Styles for each template can be redifined using classes : modal-drawer-header, modal-drawer-content, modal-drawer-action-bar
