Modal component

Govern modal UI component.

The modal component opens as a dialog. Default actions are Cancel and Confirm, for any other actions, the buttons must be implemented as part of the content of the modal.

The modal can always be dismissed by pressing the ESC button.

The size of the modal is set with the additionalClasses property. 4 default sizes are defined in the stylesheet, which controls the width of the modal.
