Dynamic Position

Popup menu will switch positions if there is not enought room underneath to render full menu. Use scroll Up to trigger position change

Right button will open a popup which will open on left side

Dynamic Position Popup

Popup menu will switch position if there are not enought room above/under or top/left from the menu

Right button will open a popup which will open on left side

Dynamic position will set up correct display mode. Check out 4 menus positioned in each corner.
Press 'ESC' to close fullscreen mode.
