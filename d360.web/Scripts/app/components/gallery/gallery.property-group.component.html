Property Group Component

Wrapper component for form controls.

Implementation notes
  • You must have the [formcontrolname] or [name] attributes set on each input.
  • Requires the use of either the reactive or template driven forms for invalid/required counts.
  • The inputs should be wrapped in a div marked as the inputs for that property group(see basic usage).
