Configurable Labels

The labels for true / false are configurable.







With optional selection

By default an option must be selected however it is possible to enable no selection via the alwaysSet property. Simply click on the selected value a second time to unselect or initialize ngModel to undefined.





Binding

2-way binding between the switch control is supported using ngModel

Disabled

As with all form controls this input can be disabled





Form Validation

The switch control support Angular native form validation. Validators such as required can be used and styles can be specified on the control to meet your needs.
