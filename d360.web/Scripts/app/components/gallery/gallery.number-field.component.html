Template driven forms with min/max enforcement

Because min/max validation for the underlying HTML element is done by a validation function for reactive forms, custom min/max validation has been added to the template driven element. The enforceMaxMin property must be set to true, and the two errors are overMax and underMin. Min is set to -3 and max is set to 3.
