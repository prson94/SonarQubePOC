Dropdown Bagbe Compomnent

Functions of the component:
display the status (or other analogical, dynamic piece of information) in the details sidepanel of an item,
enable the user to change the status by selecting another item from the associated list.

Basic Usage
            <ig-dropdown-badge>
                <ig-dropdown-badge-option [value]="1" label="One"></ig-dropdown-badge-option>
                <ig-dropdown-badge-option [value]="2" label="Two"></ig-dropdown-badge-option>
                <ig-dropdown-badge-option [value]="3" label="Three"></ig-dropdown-badge-option>
            </ig-dropdown-badge>
