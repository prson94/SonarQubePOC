Global Fields
Subject Area Friendly Name
This allows for the renaming of the Subject Area field for all artifact types. The default is "Subject Area." After changing this value, if you wish to use the default value, simply remove the value in the field below.

Subject Area Nodes Friendly Name
This allows for the renaming of Subject Area Nodes field. The default is "Subject Area Nodes." After changing this value, if you wish to use the default value, simply remove the value in the field below.
