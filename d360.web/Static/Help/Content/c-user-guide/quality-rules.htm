Quality rules

Many organizations utilize various tactics and software solutions to make sure that the data that they use for business meets agreed upon, measurable quality standards. Infogix Data3Sixty is able to incorporate data quality outputs from various outside sources into your data governance effort.

Incorporating data quality outputs

Data quality is an assessment of the fitness of data to serve its purpose in a given context. Many organizations utilize dedicated software solutions to ensure that the data that they use for business meets agreed upon, measurable quality standards. Those standards are typically expressed as pass rate percentages. If your organization has a data quality process in place, you can take the outputs of that process, the percentages, and incorporate those percentages into your data governance effort.

Infogix Data3Sixty does not apply the data quality checks itself. Rather it accepts the outputs of outside data quality processes, passed to the product by an API (Application Programming Interface, a set of developer interfaces which allow software applications to exchange data and execute logic without user interaction).

Quality dimensions

When organizations check data quality, they typically focus on the quality dimensions described here:

Quality Dimension

 Definition
Accuracy

A validation that compares data element values to a domain of expected, acceptable values or to expected ranges of values, or both.
Completeness

A validation that verifies that a source field is not empty when a value is required.
Conformity

A validation that verifies that data element values conform to an expected format, pattern, or encoding.
Consistency

A validation that verifies that a data element value is consistent with the value of another field or fields on the same record.
Duplication

A validation that verifies that a data element value is unique
Integrity

A validation that identifies missing data within relationship linkages

Applying quality rules to assets

In order to incorporate data quality indicators into your governance effort, your organization starts by setting up data quality rules, based on the quality dimensions described above. Those rules should mirror the data quality rules that you have in place in your data quality solution. Relationships are then established between your data quality rules and your artifact assets.
