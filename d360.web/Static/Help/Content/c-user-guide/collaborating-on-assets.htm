Collaborating on assets

 

Infogix Data3Sixty provides a collaborative platform for users to follow and post comments or hold discussions on an artifact. This section will cover the following topics:

  • Community overview: Use the Community page for an overview of the breakdown of responsibilities across the users in your organization.
  • Following assets: Register interest in particular assets to be notified as they are updated
  • Discussing assets: Start or participate in the discussion of assets
  • Raising issues: Raise an issue or concern regarding an asset
