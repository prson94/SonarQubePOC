Raising issues

In addition to suggesting changes and modifications to artifacts, you can also raise issues within Infogix Data3Sixty.

  1. Click the Take Action button:

     

     

  2. On the Take Action page, select the issue that you are reporting.
  3. Select a severity level in the Criticality field and add a description of the defect in the Description Of Problem field.
  4. Click Save.
