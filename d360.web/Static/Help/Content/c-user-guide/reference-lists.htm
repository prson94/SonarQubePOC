Reference lists

Reference Lists are simply lists of enumerations to be made available as custom field values, displayed and chosen from drop-down lists.

Common examples of reference lists are:

  • State Codes: AL, AK, AZ, AR, CA, CO...
  • Status: Draft, Under Review, Certified
  • GDPR Compliant: NA, Yes, No
  • Credit Cards: American Express, Discover, Mastercard, Visa
