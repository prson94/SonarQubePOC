Following workflows

A workflow in Infogix Data3Sixty is a set of steps that can be applied to an artifact to control how the item is managed within the business glossary. When you are working with existing artifacts, or proposing new artifacts to be added to the glossary, you will need to follow the workflow steps set out by your organization's governance program.

Tip: This topic provides an understanding of workflows for end users. If you are an Administrator and want to set up a new workflow, see Establishing workflows.

Understanding workflows

In Infogix Data3Sixty, there are three common types of workflow:

Workflow type Description

Proposal workflow

The proposal of a new artifact defined within the glossary.

  1. A data steward proposes a new artifact to add to the glossary, for example, a Business Term, a report, an Application or any other type of artifact that has been defined.
  2. The data steward selects a relevant governing domain so that the item can be routed to the governing owners for review and approval.
  3. If approved, the term and notification is routed back to the data steward to add additional governance components as determined by your organization's data governance program, such as the business owner, additional stewards or business metadata.
Certification workflow

The certification that an artifact within the glossary meets the governance criteria set out by your organization, for example, verifying expected metadata or levels of ownership on a selected artifact.

  1. This is typically a follow on step to the proposal workflow. Once a new artifact has been added to the glossary, and the data steward has added the required metadata (see proposal workflow above), the data steward can then start the certification workflow for the item.

    As well as applying to new items, a certification workflow can also be scheduled periodically for a set of artifacts, e.g. the investment team may want to have their business terms certified every six months.
  2. The item is routed to the responsible party for review and certification. The relevant owners of the artifact will receive an email notification requesting their approval.
  3. The approvers certify that the artifact is fit for use by the organization.
  4. Once the item has been reviewed and approved, a certification status is applied to the artifact to inform users that the item has been reviewed and that all governance criteria and responsibilities are populated within the glossary.
Issue workflow This is a separate type of workflow that allows you to raise issues, tag them to specific artifacts and route them to the responsible people for action.

Workflow Monitoring

To see a list of workflows on the system, click the Monitor button on the left of the screen to open the Workflow Monitor page:

Selecting a workflow from the Workflows panel will display the corresponding flowchart on the right of the page. You can select specific steps of the flowchart to view more information.

Below the Workflows panel, you will see a My Assignments panel showing a list of tasks assigned to you.
