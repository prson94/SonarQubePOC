Navigating the user interface

This topic describes the main areas of the default welcome screen. You can customize the interface to suit your business needs, so you may find that your organization has a slightly different implementation to the one shown here.

1. Navigation icons

The icons listed on the left of the screen are the primary means to navigate the user interface.

Hover over an icon to see the name of the icon, and in some cases links to related items.

Note: The user interface is highly customizable. The navigation icons that are visible to you depend on the user interface settings established by your administrator. If you have administrator permissions and want to customize the home page, see Customizing the application.

Icon Description
Favorites
Glossary - Contains all business assets that have been defined for your organization.
Models - Hierarchical classification for grouping a set of business assets. Models are typically broken down by business function, for example Human Resources and Finance.
Data Quality - A perception or an assessment of the fitness of data to serve its purpose in a given context.
Policies - Governance and compliance to support the business assets. A policy can be an industry or governmental regulation such as GDPR, or an internal IT or security policy.
Reference - Source of associated values to enrich the governed data, for example country codes.
Fusion - Technical and external data which can be loaded for use with the glossary.
Community - Investigate the assigned business owners, data stewards and domain owners
Monitor - Track your workflows and assignments.
Administration - If you have administrator permissions, you can customize the display.

2. Toolbar

The toolbar provides a number of quick access buttons. You will see some or all of the following buttons depending on your settings and which part of the application you are in:

Button Description

Click the Take Action button to take an action on an asset, see Raising issues.

Note: The visibility of the Take Action button depends on the settings established by your administrator.

The Take Action button is only visible if the Disable Take Action option is not selected on the Administration > Settings page.

The shopping cart is reserved for future use.

The visibility of this button depends on the settings established by your administrator on the Administration > Settings page.

Click the Add to favorites button to add the current page to your favorites. You can access your favorites from the top of the left navigation pane.

Click the Make this my home page button to set the current page as your home page. Next time you login, you will be taken directly to this page.

Note: The URL containing /home will still take you to the system-wide defined home page, for example: client.data3sixty.com/home. You will be taken to your designated home page with the base URL, for example client.data3sixty.com. If you have shortcuts set up on your browser, verify the URL to be sure of which page you will be taken to.
Click the Follow this item button to mark the asset that you are viewing as being followed. You will then be able to see the asset on your profile page under the Items Follow icon.
Click the Help button to open the online user and administration guides.
Click the Search button to search for assets and other items.
Click the Sign out button to log out of the application.
Click the Go to your profile button to navigate to your profile page.
