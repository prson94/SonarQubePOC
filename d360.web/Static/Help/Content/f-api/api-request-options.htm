API request options

There are several options that you can add to the base API request to specify data sorting, selecting fields, paging, and filtering. To add an option, append the question mark (?) to the URL and add the option.

Note: Syntax errors in the API request generally trigger generic errors. Please check spelling and syntax carefully for failed requests.

Sorting

Your administrator can configure one or more fields to allow sorting. The administrator must specify Allow Sort when the field definition is created in the service version. When enabled, this allows you to sort returned results on a specified field.

The syntax for this option is _order=<field_name>

For example, if your administrator defined a field named LastYearOfAccount that is enabled for sorting, the following request would return data sorted by LastYearOfAccount:

https://client.data3sixty.com/services/custom/AcmeInc/RiskCodes/1.5/ RiskValues?_order=LastYearOfAccount

 

The default sort order is ascending. You can reverse the default sort order by including a negative symbol (-) just before the field name. For example:

https://client.data3sixty.com/services/custom/AcmeInc/RiskCodes/1.5/ RiskValues?_order=-LastYearOfAccount

 

You can also specify multiple fields for sorting. The first field in the provided list has highest precedence for the sort order.

The following table details what field types may be used for sorting and what type of sort is used for each:

Field type Sort used
Numbers Ordinal
Strings Alphabetically
URIs Alphabetically
Dates Chronologically
Times Chronologically
Datetimes Chronologically
Enumerations Alphabetically

Selecting fields

Your administrator can configure one or more fields with the Allow Select option. This option allows you to return only data for the selected field. If multiple fields are specified, data is returned for only those fields. Your administrator must specify Allow Select when the field definition is created in the service version.

The syntax for this option is _select=<field_name>

For example:

https://client.data3sixty.com/services/custom/AcmeInc/RiskCodes/1.5/ RiskValues?_select=LastYearofAccount

 

This filter also allows you to request data from several fields at one time. When specifying multiple fields, provide a comma-separated list, for example:

https://client.data3sixty.com/services/custom/AcmeInc/RiskCodes/1.5/ RiskValues?_select=LastYearofAccount,CurrentStatus

Paging

As some requested data sets can be very large, the Custom API supports paging.

The syntax for this option is _pageNum=<number>

For example, the following request returns data from page 2 only:

https://client.data3sixty.com/services/custom/AcmeInc/RiskCodes/1.5/ RiskValues?_pageNum=2

 

The default page size is 200 entries, which is also the maximum page size. You may, however, request smaller pages by using the _pageSize=<number> filter. For example:

https://client.data3sixty.com/services/custom/AcmeInc/RiskCodes/1.5/ RiskValues?_pageSize=50
