Adding fields

  • You have created a version, see Creating the version.

Once you have created a version, the next step is to add fields to the configuration. If a field is not included in the definition, end users will not be able to access data from that field via the API. For example, if an artifact definition has fields which contain personal data, you can exclude these fields from the definition. This prohibits users from accessing that data via an API call.

 

To add fields:

  1. On the Endpoint detail page in the Fields panel, click the Add button.

    The New Version Field page displays.

  2. On the New Version Field page, configure the field by completing the following options:
    • Field - Select the field name from the list. Values include all available fields from the object selected in the Asset Type field in the endpoint definition.
    • Allow Sort - Enables sorting of returned data (optional).
    • Allow Filter - Enables filtering of returned data (optional).
    • Allow Select - Allows users to specify one or more fields. Only data for the specified fields will be returned for each object (optional).
    • Json Field Name Override - If data is being returned in the JSON format (default), the override value is used in place of the actual field name (optional).
    • Xml Field Name Override - If data is being returned in the XML format, the override value is used in place of the actual field name (optional).
  3. Click Save.

The final step in configuring the Custom API is to create the URI types used in the connection, see Creating the URI types.
