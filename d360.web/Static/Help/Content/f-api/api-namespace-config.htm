Configuring a namespace

  • You have created an endpoint, see Adding service endpoints.

 

After you have created an endpoint, you can optionally configure a namespace:

  1. On the service detail page, click the Namespace icon in the upper right to display the Namespaces page.
  2. On the Namespaces page, click the Add button in the upper right.

    The New Namespace page displays.

  3. On the New Namespace page, enter values for the following:
    • Element Name (required) - To associate the namespace with a custom element name, the Element Name field value must exactly match the value configured in an endpoint's Item Element Name field.

      Note: If the Element Name field value does not match any endpoint Item Element Name field value, the namespace is associated with all configured endpoints in the entire service by default.

    • Namespace (required)
  4. Click Save.

The next step in configuring the Custom API is adding a version, see Creating the version.
