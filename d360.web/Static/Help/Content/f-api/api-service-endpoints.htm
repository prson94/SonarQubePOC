Adding service endpoints

  • You have created an API service, see Creating an API service.

The next step after creating an API service is to add the required endpoints. An endpoint is associated with a specific data set. So, for example, an endpoint associated with customer data might be named CustomerAccounts.

Tip: The endpoint name should be brief, but easy to read and understand.

 

To create an endpoint:

  1. In the Services panel, locate the service and click the service name to open the service detail page.
  2. On the service detail page, at the top of the Endpoints panel, click the Add button.

    The New Endpoint page displays.

  3. On the New Endpoint page, enter the following required information:
    • Name - Alphanumeric value.
    • URI Segment - Alphanumeric value.
    • Item Element Name - This is an optional name that replaces the default "item" label for an XML element. If you configure a value for this field, you can use the value to specify a custom namespace to use in conjunction with the element name. See Configuring a namespace for details.
  4. Click Save.

Once you have created endpoints and any optional namespaces (see Configuring a namespace), the next step is to create the version, see Creating the version.
