Custom API guide

The topics in this section of the help provide information about the Infogix Data3Sixty Govern Custom API. This information is intended for administrators who are responsible for application configuration and maintenance and technical users who use the API to query Infogix Data3Sixty Govern information.

Note: All users must have appropriate permissions for access to the application.

 

The Custom API was developed to allow users to make requests through the API URI to obtain specific data from Infogix Data3Sixty Govern objects. Data is returned either in an XML or JSON format.

Note: By default, JSON is the data output format. In the API client, you can specify that results be returned in XML.

 

For administrative information on configuring the Custom API, see Configuring the Custom API interface

For information on end user queries, see Using the API service.
