Creating the version

  • You have created a service, see Creating an API service.
  • You have created an endpoint, see Adding service endpoints.
  • You have optionally created a namespace, see Configuring a namespace.

 

The next step in configuring the Custom API is adding a version. Versions allow you as the administrator to create multiple configurations for the same service endpoint.

For example, over time an artifact definition may have to be revised to include new fields as business requirements evolve, or certain fields may become deprecated. To allow new fields to be used, or old fields to be removed from use, you can:

  • Create a version that contains new fields.
  • Create a version that removes deprecated fields.
  • Retain older versions that may be needed for auditing or reporting purposes.

 

To add a version:

  1. In the Endpoints panel, locate the endpoint and click the endpoint name to open the endpoint detail page.
  2. On the endpoint detail page in the Versions panel, click the Add button.

    The New Version page displays.

  3. On the New Version page, enter the following required information:
    • URI Segment - Alphanumeric value.
    • Major Version - Whole number.
    • Minor Version - Whole number.
    • Asset Type - Select the object to be queried via the API connection from the list.
  4. Click Save.

The next step is to add fields to the configuration, see Adding fields.
