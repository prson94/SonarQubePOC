Building an API URL

For every configured API service, there is a unique URL that allows users to query Infogix Data3Sixty Govern object data. Your administrator configures and maintains these connections.

A single connection service may have many endpoints, versions, and URI types associated with it. Your administrator can provide details on the base URL and various endpoints, versions, and URI types available for each service.

URI types

It is important to understand that there are two specific types of URI connections:

  • Singleton - Allows the return of data for only one object instance.
  • Collection - Allows the return of data for multiple objects.

If a singleton URI Type is used in an API request, the request must specify an asset identity so a single item is returned. Failure to supply an identity results in an error. You may also use a collection URI Type to return data for a single object by using a filter, see the following section URL request syntax.

URL request syntax

The syntax of the API request follows a specific format and allows you to add options to make data selections. The general syntax of an API request is:

https://hostname.com/services/custom/service_name/endpoint_name/version/ URI_type_name

 

where:

  • https is the protocol
  • hostname.com is the hostname for your Infogix Data3Sixty Govern deployment
  • services/custom are the Custom API service identifiers
  • service_name is the name of the defined service
  • endpoint_name is the configured endpoint
  • version is the version number of the service
  • URI_type_name is the URI connection type (Singleton or Collection) configured for the request

With the exception of protocol and service identifiers, these components are all custom to your environment and defined by your administrator.

In addition, the Custom API supports several options to select and organize data. For details on using these options, see API request options.

Collection URI Type Requests

To use a collection URI type, use the components listed above to construct the request. For example, given a base URL of https://client.data3sixty.com/services/custom, adding the following connection information constructs an API request to return all data found by the collection URI type "AllValues":

  • URI: AcmeInc
  • Endpoint: RiskCodes
  • Version: 1.5
  • URI Type Name: AllValues (a collection URI type)

The complete API URL request is:

https://client.data3sixty.com/services/custom/AcmeInc/RiskCodes/1.5/AllValues

Singleton URI type requests

Singleton URI types require the inclusion of the asset identity. For example, the following is an API request using a singleton URI "SingleResult" for an asset named "DFAST_10-50":

https://client.data3sixty.com/services/custom/AcmeInc/1.5/SingleResult/ DFAST_10-50
