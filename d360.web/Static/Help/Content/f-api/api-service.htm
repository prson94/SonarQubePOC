Creating an API service

For users to be able to request data using the API, as a user with administrative permissions, you must first configure the service in the application, as follows:

  1. Log in to Infogix Data3Sixty Govern as an administrative user.
  2. From the menu on the left of the screen, click the Administration icon and select Integration > Custom API.

    The Services page displays.

  3. To create a new service, click the Add button in the upper right.
  4. In the New ApiService page, complete the following required fields:
    • Name - Alphanumeric value. Generally, the Name field value is limited to 250 characters.
    • URI Segment - Alphanumeric value. This value is used as the URI value.
    • Cache Max Age - Maximum number of seconds before a cache refresh. The optimal maximum cache age depends on the data. For example, if data is a list of states and provinces, the cache may be configured for a longer period, as these lists do not change often. However, if data consists of user or customer accounts, the cache age should be shorter to avoid cached data becoming stale.
  5. Click Save.

Caution: It is highly recommended that no spaces are included in any configuration names and URI segment field values. All values used should be user-friendly and understandable, but not lengthy, as long strings are difficult for end users to remember and use successfully. Note also the following characters are not URI encoded when used as semantic characters in a path: ! $ & ' ( ) * + , ; =

 

The next step after creating an API service is to add the required endpoints, see Adding service endpoints.
