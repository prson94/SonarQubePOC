New features and enhancements

API

Feature Tracking number

Custom API HTTP HEAD support

  
The HTTP HEAD method is now supported in the custom API for GET methods. The HEAD method is identical to GET, except that the server does not return a message-body in the response. GOV-5040

Custom API List fields

  
For list fields, you can now choose to display the actual Reference List items rather than the default display value. GOV-5080

API key display

  

A new option was added to the Administration > Settings page under the Features section to Display API Key. When selected, any user will be able to see their API Key on their User Profile page. If not selected, non-admin users will not be able to see their API on the User Profile page.

Note: Users with Administrative access will always be able to see their API regardless of this option.

 GOV-5085

Custom API help documentation

  
The Custom API help content has been integrated into the product HTML help. This content, aimed at administrators who are responsible for configuring the Custom API and technical users who use the API to query Infogix Data3Sixty Govern information, can now easily be accessed from within the product by clicking the Help button on the toolbar. GOV-5124

Relationships

Feature Tracking number

Relationship states

  
In addition to displaying relationships that are in an Active state, complex lookup fields now display all relationships that are in either an Active state (the default) or in a Pending Add state. Generally, relationships are only placed in a Pending Add state if the state is changed via a workflow. GOV-5119

Predicate inverse on filter labels

  

Impact diagrams now include predicate inverse information in cases where the diagram shows the inverse relationship, for example the predicate inverse "stored in" as opposed to the predicate "stores".

Corrected issues

Issue summary Issue number

Fusion rules trigger

  
Resolved an issue where the IGC Webjob was not triggering the execution of fusion rules. GOV-4795

Predicates list

  

Internally required relationships that were created for parent / child assets are no longer included in the Predicates list. Only user-created predicates are now included in the Predicates list.

 GOV-5007

Predicate functional types

  

Restrictions were added so that only the predicate functional types that can be used to create custom predicates, or used in custom relationships, are displayed and are able to be selected. Previously, system-used predicate functional types were displayed and were able to be selected. Now, the predicate types reserved for internal system use do not display (Inter-type Hierarchy, Intra-type Hierarchy, Object Ownership, Reference Data Lineage).

Note: If your system includes user defined relationships that use the system predicate types, they will need to be updated.

 GOV-5009

Deleted items

  
Resolved an issue where deleting an object from the application did not remove the responsibilities for the item which were then counted in the Community page, resulting in inaccurate counts and unnamed items appearing in the Community Items Owned panel and on a user's Resource page. GOV-5054

Export to Excel from artifact list page

  

Resolved an issue where exporting to Excel from an artifact list page filtered by a none listable top level field exported all items rather than only those displayed in the filtered view.

For example, on the Business Terms page, if you had applied a filter to show only the items which contained the word "date", if you then exported the list to Excel, you would see that all items were exported rather than only the items containing the word "date".

GOV-5058

Column order on artifact pages

  
The order of the Name and Parent columns has been changed back so that the Parent column appears before the Name column on the artifact list page and on the artifact detail page. GOV-5077

Fusion List page column sorting

  

Resolved an issue where dates were being sorted as strings rather than as dates on the Fusion list page.

 GOV-5087

Custom status icons

  

An update was made to the algorithm that designates the color of the starburst for different statuses on the artifact list page. Previously, the colors for different statuses were very similar and it was difficult to differentiate between them. Now, the colors are more distinctive.

Note: The colors for status Draft, Under Review, and Certified will remain the same (Draft = Gray, Under Review = Orange, and Certified = Green). These are system used statuses for the Certification Workflow and the colors for them are hard coded.

 GOV-5089

Defining workflows

  
When creating a workflow, the system previously allowed you to remove the Change Type and save or move on to the next step, resulting in errors. Now, you cannot save a workflow or move to the next step if the Change Type field is blank. GOV-5090

Items Owned timeout error

  
Resolved a timeout error when selecting to view Items Owned from a user's Resource page on systems with a large number of users. GOV-5094

Sidebar icon

  

Resolved an issue where the incorrect icon and title were being shown for the Responsibilities sidebar in the reference item page.

 GOV-5106

Artifact list load time

  
The database query that fetches the list of glossary terms in the application has been optimized for non-administrator users. GOV-5108
   

The database query that fetches lookup values for lists on artifact types has been optimized.

 GOV-5109

Invalid field type

  

If there are artifacts that use a field type that is based on a relationship that no longer exists, you are now able to edit the artifacts that use that field type.

 GOV-5120

Permissions control

  
Resolved an issue where users were able to see artifact details for items which they did not have the required permissions to view. GOV-5024
   
Resolved an issue where users were able to export artifacts for which they did not have the required permissions to view. GOV-5130
   
Resolved an issue where users who had the required permissions to view a dashboard were not able to see the dashboard. GOV-5042

Open action details tooltip

  
The tooltips for actions have been fixed so that they appear in the action details section of the application. GOV-5126

Community pie chart number format

  
The number format for the thousand separator on the Community page has been changed from being a space to a comma for consistency with the rest of the application. GOV-5129

Edit Relationship Types

  

Resolved an issue on the Administration > MetaModel > Relationships page where it was possible to edit a selected Relationship Type but see the field definition screen for a different Relationship Type.

 GOV-5134

Bulk loading

  
Resolved an issue with bulk loading in cases where one of the key fields was a lookup which caused a duplication of existing items with the same key field(s). GOV-5140

Fusion attribute name

  
Resolved an issue where if a Fusion attribute did not have a textpath value, the word "Name" was shown in the Items Owned panel. The Items Owned panel is visible in both the user's Resource page and in the Community section of the application. GOV-5152

Field Definition panel values

  
Resolved an issue in the Administration > Field Definition panel where you could end up with the wrong default List Display Format value when configuring a new list field. GOV-5155
