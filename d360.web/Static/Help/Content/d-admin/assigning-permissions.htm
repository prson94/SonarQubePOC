Assigning permissions

You can assign permissions to information assets to control the level of access to grant to an associated responsibility type, to indicate whether an individual who has that responsibility can simply view items, create them, update them or delete them. For more information on responsibility types, see Establishing responsibilities.

 

The following example guides you through the steps required to assign permissions to an asset for a responsibility type, in this case assigning read only permission to the Report artifact for the Report Viewer responsibility type.

  1. Click the Administration icon on the left of the screen and select Artifacts.
  2. In the Artifact Types panel, select the artifact for which you want to assign permissions. In this case, select Reports.

     

    The Permissions panel lists all responsibility types that are associated with the selected artifact.

  3. In the Permissions panel, click the arrow to the left of the name of the responsibility type for which you want to assign permissions:

     

     

  4. Select the check boxes associated with the permission level that you want to assign. In this example, you want to assign read only access to Report Viewers on the Reports artifact type, so select the Read check boxes:

     

    • Root - Refers to the permission level for the selected artifact type. In this example, selecting Read would allow Report Viewer users to view reports. If you were to also select Create, the users would be able to create a new report. Also controls the ownership of the selected artifact.
    • Governance - This column does not currently have any effect, and will be removed or changed in a future release. Ownership is controlled by your selection in the Root column.
    • Relationship - Refers to the relationships associated with the selected artifact type. In this example, selecting Read would allow Report Viewer users to view report-related relationships.

     

    You can select any combination of permission levels for a selected responsibility type on a given artifact.

     

    Tip: The same responsibility can have different permissions on different objects.

     

  5. Click Save Changes.

 

After you have created a responsibility type and assigned permissions, you can establish rules to further tailor the responsibility assignment to specific users or group, see Assigning users or groups to responsibilities
