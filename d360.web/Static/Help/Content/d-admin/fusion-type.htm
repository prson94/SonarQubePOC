Creating a custom Fusion type

When you are connecting to a new database or file type, you will first need to create a Fusion type to fit the metadata layout of your system.

 

  1. From the Administration menu on the left of the screen, select Integration > Fusion.
  2. Click the Add button in the top right corner of the Fusion panel:

    The Add Fusion Type panel will open, requesting information about your new Fusion type.

  3. Enter a Name and a Description for the new Fusion item.
  4. Optionally, you can set a Background Color and Text Color to represent the item when it is displayed in lineage diagrams.
  5. Click Save.

    The main Fusion page will refresh, showing your new Fusion type in the Fusion panel.

  6. The next step is to build a structure to represent the metadata of your new Fusion type:
    1. In the Fusion panel, select your new Fusion type.
    2. Clicking the Add button in the top right corner of the Structure panel.
    3. Type a Name and a Description for the structural item, e.g. Table, Column, View.
    4. Optionally, you can set a Background Color and Text Color to represent the item when it is displayed in lineage diagrams.
    5. When you have finished entering information in the Structure panel, click Save.
  7. Optionally, you can add a new field to your structural type by selecting the structure then clicking the Add icon in the top right corner of the Fields panel.
  8. To add another structural type at the same level as the one you created in the previous step, follow the same steps. To create a child type, click the Add button on the row that will serve as the parent.
