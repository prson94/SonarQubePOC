Changing the Fusion agent log level

By default, all events are logged. To save server disk space, you can change the log level as follows:

  1. Navigate to the "app" folder in your Fusion agent installation directory.
  2. Open the Logging.config file.
  3. Locate the level value line: <level value="ALL" />
  4. Edit the level value as required, choosing from the following options:

     

    • ALL - All events generated by the agent are logged.
    • DEBUG - All events marked as Debug or higher are logged.
    • INFO - All events marked as INFO or higher are logged.
    • WARN - All events marked as WARN or higher are logged.

      Note: WARN is the recommended log level.

    • ERROR - All events marked as ERROR or higher are logged.
    • FATAL - All events marked as FATAL or higher are logged.
    • OFF - Turns off all logging.

    For example, change the line to <level value="WARN" /> to set the log level to WARN.
