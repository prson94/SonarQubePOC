Bulk loading users

You can add users to your system via bulk loading.

Tip: If you are not familiar with the concept of Bulk Loading, see Bulk loading.

Note: It is not possible to import groups via the Bulk Loader. However, you can assign users to groups that you have already created, see Assigning users to groups via bulk loading.

 

  1. Click the Administration icon on the left of the screen and select Integration > Bulk Loader.
  2. In the top right corner of the History panel, click the Add button:

    The Upload a spreadsheet job panel opens.

  3. Select Users/Groups from the Action list.
  4. Select Users from the Relationships Type list.

    You will see a depiction of the spreadsheet columns, with any mandatory columns shown in bold:

  5. You can either use a spreadsheet that you have already created, ensuring that you include the required columns shown in bold, or, you can download a spreadsheet containing these columns by clicking the Download Spreadsheet link.
  6. Complete the spreadsheet by adding the required information to the bold columns.

    Note: The valid options for the Status column are Active and Inactive.

  7. Save the spreadsheet, then return to the Infogix Data3Sixty Govern user interface.
  8. Click Choose file to navigate to your spreadsheet and click Open on the Windows file navigation window.
  9. Click Save to bulk upload the users.

The Load Details panel will display a list of imported records.

If there are any errors, for example if you are missing an entry in one of the bold columns, you can download the spreadsheet to investigate the errors by clicking the Export Errors to Excel button:

Tip: If the system has not refreshed immediately, you can click the Refresh button to see the results of your bulk upload.

Assigning users to groups via bulk loading

You can assign users to groups via bulk loading in much the same way that you can bulk import users, but instead of selecting Users from the Relationships Type list, select Group Membership, as follows:

  1. Click the Administration icon on the left of the screen and select Integration > Bulk Loader.
  2. In the top right corner of the History panel, click the Add button:

    The Upload a spreadsheet job panel opens.

  3. Select Users/Groups from the Action list.
  4. Select Group Membership from the Relationships Type list.

    You will see a depiction of the spreadsheet columns, with any mandatory columns shown in bold.

    The mandatory columns for Group Membership are Action, Group Name and User Email.

  5. You can either use a spreadsheet that you have already created, ensuring that you include the required columns shown in bold, or, you can download a spreadsheet containing these columns by clicking the Download Spreadsheet link.
  6. Complete the spreadsheet by adding the required information to the bold columns.

    Note: The valid options for the Action column are Add and Remove.

    Note: The Group Name must match an existing user group on your system.

  7. Save the spreadsheet, then return to the Infogix Data3Sixty Govern user interface.
  8. Click Choose file to navigate to your spreadsheet and click Open on the Windows file navigation window.
  9. Click Save to bulk assign users to groups.
