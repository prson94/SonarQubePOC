Configuring Active Directory

Infogix Data3Sixty Govern is compliant with any SAML2 federated identity server, such as Active Directory Federation Services.

The following settings should be used when setting Infogix Data3Sixty Govern up as a relying party, where <Client_environment> should be replaced with the correct path to your Infogix Data3Sixty Govern environment:

Issuer ID (App ID) https://data3sixty.com/ui
From URL https://<Client_environment>.data3sixty.com/sso/acs
Target URL https://<Client_environment>.data3sixty.com/sso/acs

 

To configure Active Directory, you must provide Infogix support with the following information:

Required information Description
Idp SSO endpoint A publicly accessible login URL.
Idp SLO endpoint A publicly accessible logoff URL, if different from above.
Expected hash algorithm  
Sign SAML assertion Y/N
Sign SAML message Y/N
Encrypt SAML message Y/N
Public certificate If provide an encrypted SAML message, please also provide a .CER file to encrypt the message with.
Expected claims
  • Username
    • Active Directory property - Email address
  • First name
    • Active Directory property - Given name
  • Last name
    • Active Directory property - Surname

Enabling SSO

You can enable SSO on all Infogix Data3Sixty Govern environments by using the same configurations within Active Directory Federation Services.

  1. Specify the relying party identifier, for example https://data3sixty.com/ui

  2. Select the Endpoints tab, then specify all Infogix Data3Sixty Govern environments as your Assertion Consumer Endpoints:

Securing SSO authentication

  1. Open Active Directory Federation Services Management Center.
  2. Expand Trust Relationships.
  3. Select Relying Party Trusts.
  4. Right-click the required trust, then click Edit Claim Rules.
  5. Select the Issuance Authorization Rules tab, then delete the default Permit Access To All Users rule.
  6. Click Add Rule, then select Permit or Deny Users Based on an Incoming Claim.
  7. For the Incoming claim type, select Group SID.
  8. Click Browse next to the Incoming claim value field and select the required group.
