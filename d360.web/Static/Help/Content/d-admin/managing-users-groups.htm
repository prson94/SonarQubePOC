Managing users and groups

Tip: You must have administrator permissions to manage users and groups.

 

If your organization deploys Infogix Data3Sixty in conjunction with an existing LDAP/AD protocol, users will be automatically created when they log in to the application, and granted read-only access. You will then need to grant additional access to selected individuals, as required.

For additional information on LDAP/AD integration, see Configuring Active Directory.

 

For non-LDAP/AD organizations, you can manually create users in Infogix Data3Sixty, see Creating new users.

 

You can create groups to enable you to cluster users together into logical categories, such as departments, or functional areas within an organization, see Creating a new group.

 

Then, as you build out business terms and assets within Infogix Data3Sixty, you can assign a user or a group as the resource for that asset.
