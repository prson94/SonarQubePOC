Customizing the application

If you have administrator permissions, you can customize the display of the application in various ways.

 

This topic describes how to customize the home screen. See also:

  • Defining fields on asset types

 

  1. Click the Administration icon on the left side of the main screen, then select Settings:

     

    You can configure the following items:

    • Custom Images - Substitute your company logo in place of the Infogix logo that appears in the top left corner of the screen.
    • IP Restrictions - Restrict access to certain IP addresses or a range of addresses.
    • Site Nav - Customize the icons that appear on the left side of the screen. You can re-order or rename the icons, select an alternative icon, or restrict permissions.
    • Home Page Customization - Modify the appearance of the default welcome screen, including adding any shortcut links to other websites.
    • Header Background/Border Color - Specify a color for the header background and border.
    • Search - Select a default value for the initially selected list of object types to search. Choose whether to enable exact match by default.
    • Default Route - Specify the default route that users will be redirected to when they log in to Infogix Data3Sixty.

     

  2. Click Save Changes to submit your customizations.
