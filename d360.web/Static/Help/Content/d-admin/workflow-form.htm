Setting up a form

When creating a workflow, you have the option to include a Form element. The Form element allows you to create a custom form that can be emailed to a user as part of your workflow. For example, you could create a form for approving or rejecting a change to a Business Asset, where the approver can accept or decline a change and add a comment.

 

If you have included a Form element in your workflow, you can customize your form as follows:

  1. Select the Form element, then in the Form panel, click the Edit tab to set up the form:

     

     

  2.   Type a Name and a Title for the form, for example, "Suggest Business Term Change". The name and title can be the same.
  3. If required, add a Description.
  4. Select a Recipient Type. Choose from the following options:
    • Initiator - The form is sent to the individual who initiated the change.
    • Responsibility - The form is sent to all individuals who have been assigned to a particular role, such as Data Steward or Subject Matter Expert.
    • Specific User - The form is sent to an individual user. When this option is selected, a conditional field will display where you must supply the email address for that user.
  5. If you would like to send an email notification, enter the email address of the Recipient who should receive the notifications, and select Send form email?. Type the text of the email in the Body field.

    Tip: You may also notice that there is a Response Type field. This setting currently has no impact and is reserved for a future release of Infogix Data3Sixty.

  6. To customize the form further, you can add additional fields by scrolling to the bottom of the Form panel and clicking the Add button:

    1. Select a Field Type. Choose from the following options:

      • boolean - A data type with two possible values; true or false.
      • integer - A whole number that can be positive, negative, or zero.
      • text - A free form string of alphanumeric characters.
      • date - A date in a recognized date format.
      • list - A list of items.
      • relationshipType - A relationship between Business Assets, for example, [contains] Glossary :: Report
    2. Add a Label for the new field. For example, if you are adding a new boolean type field, you could label the field "Approve?".
    3. Click Add.
