Establishing attributes

Attributes provide metadata enrichment and act as containers that can hold multiple fields describing the objects that are assigned to them. They can be assigned to many different types of objects, including artifacts such as a business terms and applications, or alternatively they can be applied to various taxonomies, relationships, Fusions and data domains.

 

Choose Administration > MetaModel > Attributes to view a list of existing attribute types:

Creating a new Attribute Type

  1. Click the Add button in the top right corner of the Attribute Types panel.
  2. Complete the fields in the Add Attribute Group panel:
    1. Enter a Name that will be displayed for the attribute.
    2. Type a Description of the attribute and its function.
    3. Select the Category under which you want to group the attribute.
    4. If you select Show Name in Tree, the text format name will be displayed next to the attribute value.

Allocating attributes

Once the fields have been created, an Attribute needs to be allocated to the metadata that they describe. This can include single Artifact Types, Models, Fusion, etc. or it can be a Relationship, such as "All Business Terms associated with the Investments Model".

You can add a new attribute allocation as follows:

  1. Select the attribute in the Attribute Types panel
  2. Click the Add button in the top right corner of the Allocations panel:

  3. In the New Attribute Allocation panel, select an attribute type.
