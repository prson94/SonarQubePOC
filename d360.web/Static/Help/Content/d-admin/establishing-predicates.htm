Establishing predicates

Many of the assets that you establish in Infogix Data3Sixty have links to other artifacts in the system. These links are referred to as Relationships, see Establishing relationships.

To frame the relationship, a predicate is used. A predicate is the term that links the two sides of a relationship. For example, take the two artifact types; "Report" and "Business Term", say you have a Report which contains a particular Business Term, then "Report contains Business Term" is an example of a relationship. The term that links the two artifacts, the predicate, in this case is "contains".

For every relationship, the inverse of the predicate must also be true. In the case of our example, "Report contains Business Term", this could also be written as "Business Term is contained in Report". Another common predicate is a synonym.

Each predicate is also assigned a Functional Type which controls its behavior in Infogix Data3Sixty. One of the most commonly used functional types is Grammatic Assocation which is used for synonyms, antonyms or grammatically similar terms.

 

  1. Click the Administration icon on the left of the screen and select Predicates.
  2. Click the Add icon in the top right corner to enter a new predicate.
  3. In the New Predicate screen, type a Name for your new predicate, e.g. Contains.
  4. Type the Inverse of the predicate, e.g. Is contained in.
  5. Select a Functional Type, e.g. Data Lineage.
  6. Click Save to create the new predicate.

 

You can then create relationships between artifacts, using predicates that you have created to frame the link between the two objects, see Establishing relationships.

 

To edit a predicate, click the pencil icon to the right of the predicate which you want to modify.
