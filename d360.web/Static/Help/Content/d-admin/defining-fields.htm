Defining fields on asset types

When establishing asset types on the Administration > MetaModel pages, the Field Definition table on the right is available to determine which fields should be displayed and populated as part of the definition of the selected asset type:

 

Clicking the Add button in the Field Definition panel brings up the Add Field Type panel:

 

Enter a Name for the field and choose a type from the Input Type list:

Input Type Details
Date Inserts a calendar from which to select a date.
Date With Time Inserts a calendar from which to select a date and time
Decimal Number Inserts a field in which a whole or decimal number can be entered.
Filtered Lookup Inserts a searchable list of items.
Fusion Lookup Inserts a searchable list of technology assets.
Html/Rich Text Inserts a scrollable area in which styled text can be entered.
Link Inserts two fields, one in which a simple name can be entered. The second in which a complete internet address, including protocol prefix, can be entered.
List Inserts a drop-down list from which the administrator can make a selection.
Number Inserts a field in which a whole number can be entered.
Ownership Lookup Inserts a searchable list of owners.
Reference Item List from Relationship  
Relation Lookup Inserts a searchable list of relationships.
Relationship  
Simple Text

Inserts a field in which text can be entered. Text can be required to conform to a particular pattern.
True/False

Inserts a checkbox which, when selected, indicates a true condition.

 

In addition to Name and Input Type, you can also configure the following attributes for a field:

 

API Name - The name that would be referenced when loading data using API

Category - Category is used if you would like to group similar fields together in a group.
