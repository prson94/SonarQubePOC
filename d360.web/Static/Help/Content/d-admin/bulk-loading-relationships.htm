Bulk loading objects with relationships

Tip: If you are not yet familiar with the concept of Bulk Loading, see the Bulk loading introduction topic.

 

For some bulk uploads where relationships are established between assets, you must provide both parent and child IDs.

In the following example of a Relation bulk upload action, the upload spreadsheet requires you to include the ID of the application that contains the business term.

Tip: This examples shows a Relation action, however, an Unrelation action requires the same information.

 

 

To locate the required Asset IDs, navigate to the detail page of the asset.

For example, for the Business Term "Credit Score", you would click the Glossary icon on the left of the screen and select Business Term. From the list of Business Terms, select "Credit Score" to open the detail page:
