Bulk loading

In other help topics, the methods that are described for adding new items, such as adding new Business Terms or Applications, are typically used to make small numbers of entries. To add large volumes of information, you can use bulk loading.

The Bulk Loader allows you to make multiple entries onto a spreadsheet which can then be uploaded into Infogix Data3Sixty Govern in one go. For example, you can use bulk loading to upload a series of Business Term definitions or a set of users.

Note: As a first step, you must first ensure that any custom fields required for the artifact are already in place, see Defining fields on asset types.

 

To open the Bulk Loading page, click the Administration icon on the left of the screen, and select Integration > Bulk Loader.

 

The following two topics guide you through the steps to complete a bulk upload, see:

  • Bulk loading users and group memberships
