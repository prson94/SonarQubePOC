Establishing relationships

A relationship ties two artifacts together, using a predicate as a link between the two artifacts, see Establishing predicates.

For example, take the two artifact types; "Report" and "Business Term", say you have a Report which contains a particular Business Term, then "Report contains Business Term" is an example of a relationship. The term that links the two artifacts, the predicate, in this case is "contains".

 

  1. Click the Administration icon on the left of the screen and select Relationships.
  2. Click the Add icon in the top right corner to enter a new relationship type.
  3. In the New Relationship Type screen, select a Subject e.g. Artifacts :: Reports.
  4. Select the Predicate, e.g. Contains (Data Lineage).
  5. Select an Object , e.g. Artifacts :: Business Term.
  6. Specify the Subject Cardinality and the Object Cardinality. The cardinality is the numeric limitations of one data asset compared to another, for example, one report can contain many business terms, so in this example, you may choose to select One to Many.
  7. Click Save to create the new relationship type.

 

Tip: When creating a relationship type, the subject should always be the higher level item in the relationship, compared to the object.
